# Constitution（v1.2，不可违反）

| ID | 规则 | 怎么验证 |
|---|---|---|
| C-01 | 训练、特征、已见集合只用 `train_end` 之前的数据 | 未来注入反例测试（TE-T01） |
| C-02 | 映射、Pop 分数、过滤阈值只用训练窗口计算；validation 调参；test 冻结后只评估一次 | 测试 + `reports/` 里记录 test 运行次数 |
| C-03 | 比较的模型必须用同一切分、同一协议、同一候选规则（三个哈希一致） | 门禁拒绝测试（GATE-T02） |
| C-04 | 模型、映射、已见集合、可推荐集合、Pop 回退打包在同一个 Release 里，加载时校验哈希 | 篡改映射加载失败（REL-T02） |
| C-05 | 门禁只读登记的评估文件，不接受命令行手填分数 | 门禁接口没有分数参数 |
| C-06 | Champion 指针用 `version_counter` CAS 更新；失败不改指针 | 并发 / 过期版本测试（PROM-T03/T04） |
| C-07 | 服务报告的是**实际加载**的 release，不是磁盘上的最新指针 | API-T04 |
| C-08 | 无 Champion 时服务能启动，`/ready` 503，不在 import 时崩溃 | API-T01/T02 |
| C-09 | 日志、事件、发布包里没有原始 user_id 和评论原文 | 扫描测试（REL-T05、MON-T02） |
| C-10 | 晋升、回滚默认 dry-run，`--execute` 才写 | PROM-T01 |
| C-11 | CI 离线、确定、只用合成 fixture，不下载数据集 | CI 配置审查 |
| C-12 | 文案诚实：评分评论 ≠ 购买；未交互 ≠ 负例；离线 NDCG ≠ 线上 CTR；BPR 不如 Pop 就照实写 | 报告审查 |
